## TikFinity: automatisch abspielen
1. TikFinity → **Actions & Events** → **Neue Action**
2. **Video/Animation abspielen**: passende `_alpha.webm`-Datei hochladen
3. **Event** wählen:
   - Follow → `11-kowalski-danke-fuers-folgen_alpha.webm`
   - Rose / erstes Geschenk → `08-danke_alpha.webm`
   - großes Geschenk → `07-gewonnen_alpha.webm`
4. Die TikFinity-Overlay-Adresse in **TikTok LIVE Studio** als Quelle **„Link"** einfügen (einmalig)

## Stream Deck
- Taste → Aktion **Soundboard → Audio abspielen** → MP3 aus `sounds/` → Tastenbild aus `icons/`
- Für Einspieler im Bild: In TikFinity jede Action auch per **Stream Deck / Hotkey** auslösbar machen, dann die Taste darauf legen.
